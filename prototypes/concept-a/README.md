# Concept A — Noir Cinematic

Static Stage 0 study. Serve from the repository root so shared map, package and font URLs resolve. The parent prototype server runs at `http://localhost:6006`.

- Home: `/prototypes/concept-a/?lang=en&theme=dark&view=home`
- Map: `/prototypes/concept-a/?lang=ar&theme=light&view=map`
- Parameters: `lang=en|ar`, `theme=dark|light`, `view=home|map`.
- Readiness: `window.conceptMapReady === true`.

The conversation form is a local demonstration: North Coast/Sahel or الساحل inputs move to Egypt; Saadiyat/سعديات inputs move to Abu Dhabi; other input begins with Dubai. It is not an AI implementation. Destination chips and the coastline story control also move the camera. Language and theme controls preserve the view in the URL. Voice and project controls explain their concept status instead of pretending to record or open a real listing.

The map is actual OpenFreeMap geography via the shared MapLibre helper, with visible attribution. The light marker is projected from the community coordinates on each map render. Its height does not represent a real price. All residence content is fictional and badged Demo. No developer names or project statistics are asserted.

Typeface assets are the existing licensed local fonts. Interface transitions and map flights respect reduced motion. Destination buttons provide a keyboard alternative to map gestures. The mobile composition deliberately reduces text before the map rather than shrinking the desktop conversation rail.

No production features or global application files are modified by this concept. Native Arabic language review, full WCAG conformance, actual AI, production frame rate, real-world data trust and all downstream product flows remain Stage 1+ work.
