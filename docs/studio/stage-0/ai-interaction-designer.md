# Stage 0 · AI Interaction Designer

## Starting person and job

Elena arrives knowing what her family needs, but not how Dubai fits together. Her first useful action is a sentence, followed by a camera move and an explanation she can inspect. Sheikha's equivalent journey begins in Arabic and treats the conversation as private correspondence, never a lead-capture form.

## Proposed interaction grammar

The composer remains the primary action on Home and Explore. An input produces three coordinated outputs: a concise response, a structured generative card, and a visible map command. The Brief accumulates expressed constraints only; inference is labelled and editable. Selection moves the camera and opens the associated evidence, without replacing the conversation. A recommendation carries two reasons tied to the Brief and one trade-off. Silence and measured transitions are preferable to simulated thinking theatrics.

The Glass Atlas prototype illustrates this grammar with deterministic demonstrations: type a market, see the camera respond, submit to reveal an area note, three explicitly fictional project choices, and a visible Brief. Selecting a project moves the map. Demonstrations have no implied live agent, live availability, or private storage. Voice is a visible concept affordance with an honest unavailable explanation, not a fabricated transcript.

## Production contract for later stages

Each tool result maps to an allowlisted component: project card, comparison, source-backed area panel, payment timeline, itinerary, or developer record. Map effects are separately typed commands and do not smuggle inventory into the client. A streamed result first states the action, then reveals the result; failed calls retain the user's text and offer a meaningful recovery. Advisory questions offer a human handoff, and all sharing requires a distinct explicit action.

The Brief fields are purpose, budget and currency, places, timeline, must-haves and deal-breakers. Editing a field re-ranks visible results; mutation confirmation is reserved for saves, viewing requests and handoffs. Taste memory is opt-in, viewable and deletable. Currency always travels with every numeric amount.

## Disagreement and decision

A permanently visible chat log competes with the map and implies a generic assistant. The proposed resolution is a compact response journal over the map, not a chatbot bubble docked beside a portal. Desktop keeps the Brief in a separate compact instrument. Mobile shows the selected response in a bottom sheet and exposes the Brief in one tap. The prototype's simpler stacked mobile panel is a concept demonstration, not a claim that drag-sheet production behavior exists.

## Evidence required before acceptance

Record EN and AR versions of all three named persona scripts. Assert that each response's project identifiers and sources came from authorized tool results. Verify Brief editing, camera actions, cancellation, keyboard return to composer, a screen reader live region, reduced motion and tool failure. No review score is claimed before captured evidence.
