# Stage 2 · AI Interaction Designer

Elena’s job is to understand where a family could live, before she learns Dubai’s neighbourhood names. The conversation must change the geography in front of her. The approved Noir Atlas keeps the map as the primary canvas and uses a quiet, persistent conversation rail, becoming a draggable sheet on a phone.

Typed places, lifestyle layers and travel-time requests drive the shared deterministic interpreter. This stage names that capability “Local map interpretation”; it never impersonates a live model. The client’s original words remain editable. Unsupported budgets or property requirements are not represented as satisfied filters. Recommendations are location selections with geographic reasons, source dates and an explicit availability or uncertainty trade-off.

Five map stories have captions, manual previous/next controls and optional playback. No story starts playing without a gesture. Office and school locations are picked deliberately on the map and remain in page memory. Approximate reach areas and straight-line comparison estimates disclose their method; they are not traffic routing.

Disagreement: adding every control beside the prompt would weaken conversation-first hierarchy. Decision: the composer stays visible; secondary spatial tools live in an expandable map-tools panel. Project evidence opens within the conversation, preserving the map context. Full agent tool use, retained taste memory and streaming generative UI belong to Stage 3.

## v2 review response

Comparison is now part of the conversation rail on every viewport; the map remains clear to show the selected connections. Cross-border or long-distance comparisons show distance without implying a driving route. Each story stop has a specific geographic caption, and recommendation reasons name the actual community. The selected project and original brief pass to the existing consultant as an editable draft, with no automatic submission.

## Orientation and reading follow-up

The same composer and brief remain available while reading evidence. Editing retains multiline space across source/evidence focus; actual submission restores the compact state. Live map interpretation does not clear editing state. No new agent capability or verified-advice claim is introduced.
