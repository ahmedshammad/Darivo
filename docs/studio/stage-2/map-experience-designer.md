# Stage 2 — Map Experience Designer

Elena needs to understand places before choosing a residence. A restrained real geographic base establishes coast, neighbourhood and distance; the light columns carry only sourced or explicitly demo project data supplied by the parent. Noir and Sand are authored styles, with quieter roads and legible place names in the selected language. Columns are a relative price encoding, never building geometry. Unknown prices remain flat markers. Match controls halo opacity rather than an urgency animation.

MapLibre owns the camera, actual OpenStreetMap vector geography, building footprints/heights and Mapterhorn terrain. deck.gl owns project columns, glows and comparison/lifestyle overlays. The shared declarative contract keeps map decisions inspectable. A camera key is an explicit navigation request, and parent padding protects the selected location from the brief and mobile sheet.

Trust limits are visible: POIs and area hexes are Demo; the travel ring assumes constant speed and ignores roads/traffic; comparison distance is straight-line and travel time is an illustration. Sun direction is a time-of-day illustration, not a daylight or apartment-view study. Real project coordinates remain approximate. Reference facts remain separate from demo inventory.

If WebGL is unavailable, a projected 2D regional map uses bundled public-domain Natural Earth 1:110m land geometry with selectable project markers. It says that street/3D detail is unavailable. If external tiles also fail, the same local geometry, place labels and selectable project alternatives remain usable; there is no fabricated coastline.

Official source decisions: [OpenFreeMap custom style/hosting guide](https://openfreemap.org/quick_start/), [Mapterhorn DEM access](https://mapterhorn.com/data-access/), [Mapterhorn source attribution](https://mapterhorn.com/attribution/). Natural Earth data and [public-domain terms](https://www.naturalearthdata.com/about/terms-of-use/) are recorded in public/map-styles/README.md. Runtime hosts: tiles.openfreemap.org and tiles.mapterhorn.com. No keys, tracking or location permission required.

Review gate remains pending actual desktop/mobile captures, keyboard/fallback checks and animation timing; implementation intent is not a score.
