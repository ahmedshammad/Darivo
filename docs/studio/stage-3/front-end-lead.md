# Stage 3 — Front-end Lead

Start with Karim's two objectives on one persistent map. A single controller owns committed Brief revisions and live map actions. Arrival's typing preview remains local until submission; a committed Concierge response must never compete with that preview. Keep the existing Consultant route compatible during the transition.

Use the installed Vercel AI SDK UI message stream for typed application events. Stream interpretation, retrieval and individual grounded components as they become available. Do not simulate streaming by slicing a completed answer or delaying chunks. The model plans tools; application templates and authorized tool data supply rendered facts. Abort propagates through transport, provider and tools. Request IDs, turn IDs and increasing event sequence numbers reject stale responses and prevent replayed actions.

Public discovery works for guests with memory held only in the mounted session. Signed-in history is scoped to the current user, independently of the legacy Consultant. Reload re-authorizes component references and never runs map or write actions. A generation cannot overwrite a newer Brief edit or resurrect deleted history. Taste memory requires an explicit consent control, remains visible, and can be deleted. A natural-language privacy restriction applies before any prompt is persisted.

The hook exposes stable turns, the current Brief, status, cancellation, retry, history deletion and revisioned edits. The renderer uses typed components, never model HTML. Editable fields keep stable keys and focus. Mobile reading, source expansion and a short viewport retain the accepted Atlas behavior. Only one WebGL map is mounted; inline mini-maps are lightweight previews that target that shared map.

Validation must cover disconnects, rapid edits, history-load races, stale revisions, deletion during generation, denied inventory, repeated confirmation, bilingual keyboard navigation and partial failures. SDK integration is tested without a provider key. Existing Stage 2 strict LCP and physical-device limits remain open; a passing screenshot review does not close them.
