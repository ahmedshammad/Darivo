The consultant may interpret intent; it cannot author property facts or execute user writes. Its planning vocabulary is a strict bounded tool union. Application code owns localized prose, source presentation, prices, calculations and map coordinates. Existing scoped Property DAL and Atlas/reference repositories remain the authority.

The first complete slice is a bilingual Egypt holiday-home and Dubai investment brief: preserve both objectives and their currencies, retrieve separate grounded groups, compare, edit one market without erasing the other, cancel/retry and reload authorized history. Follow-up rounds receive authorized tool results, not raw database records. Real provider transport belongs to the parent integration; no API key is required for deterministic mock operation.

Every event is typed, sequenced and tied to a request and turn. Cancellation preserves completed content, suppresses subsequent actions and produces a terminal state. A stale Brief revision is a conflict rather than a silent overwrite. Replay rechecks access and never replays actions. Memory requires explicit purpose-specific consent; model patches may restrict but never grant it. Viewing, save and handoff are reviewable proposals only.

Acceptance evidence must include malformed plans, nonexistent and unauthorized IDs, revoked access on replay, reference-project versus demo-unit separation, privacy negations, bilingual corrections, unknown schedules, exact original price qualifiers, native/display/payment currency separation, interrupted streaming and zero invented numeric claims. No simulated evaluator result is a real-provider certification. Stage 3 remains incomplete until integration, at least sixty bilingual cases and interaction review pass.
