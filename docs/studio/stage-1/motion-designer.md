# Motion Designer — Stage 1

Document one motion grammar in the design system: 200–600ms interface transitions using a measured ease-out; camera choreography remains a separate map action. Loading must never wait for an entrance animation. Primary inputs are usable before geographic assets arrive.

Reduced motion is a first-class token/state: remove camera travel and decorative interpolation, retain immediate state feedback and focus. The system should demonstrate focus return, source-dialog opening, bottom-sheet expansion and selection without relying on motion alone.

Do not convert Stage 0's local 16.6ms median frame sample into a production-device claim. Record actual Stage 1 interaction evidence, and keep the Critic's geographic-first-frame concern as an explicit future map acceptance item. No score precedes the new captures.
