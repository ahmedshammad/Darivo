# Map Experience Designer — Stage 1

Establish geographic data contracts before the Living Map feature. Reference-project coordinates are approximate community centroids, never verified unit locations. Demo units belong only to fictional projects and fictional developers. Database constraints must enforce that boundary even when an admin or a future AI tool writes directly.

The reference data layer must expose source/date/basis with every fact. Preserve unknown dates and year/month precision; never turn the dataset compilation date into evidence retrieval. Real project availability remains on request. Synthetic POIs and area statistics require Demo labels and must not imply real schools, hospitals or journey times.

Prepare restrained Noir/Sand styles and a map-provider boundary through the foundation team. Keep attribution above visual scrims and give selected markers a clear layout-aware camera region. Stage 2 will prove map flight, terrain, columns and layers; this stage establishes their honest inputs.
