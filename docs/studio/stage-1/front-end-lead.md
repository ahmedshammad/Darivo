# Stage 1 · Front-end Lead

Start with Elena: the interface must teach her the product's grammar before it demands local property knowledge. Noir Atlas supplies the geographic structure; the design guide makes its controls, density and evidence states explicit.

Build a typed, scoped library before production feature screens. Server routes resolve locale and initial theme; client components own only interaction state. All public props use narrow unions or typed records. CSS variables use `--dv-*` within `.dv-system`, with Noir and Sand themes, logical spacing, tabular numeric typography and Amiri/Plex Arabic pairing. Parent integration may map these tokens globally without changing component semantics.

The guide is an editorial sequence: conversation, recommendation, spatial instrument, comparison/evidence, and supporting states. It must not become a generic tile grid. Components include a composer, editable brief, three project-card densities, light column, layer chip, comparison, payment timeline, trust/source badges, currency Price, stat block, bottom sheet, command palette and independent empty/loading/error states.

Accessibility is functional: labels, focus-visible, table headers, native dialogs, Escape close, restored focus, keyboard alternatives to dragging, and reduced-motion behavior. Currency values are bidi-isolated and never silently converted. Skeletons convey loading without an endless visual distraction. A retry button visibly resolves the demonstrated error.

Read the installed Next page convention before implementation: route params/searchParams are awaited promises. The library remains independent of existing production routes and schemas. Verify strict TypeScript and focused browser behavior before the full EN/AR × light/dark × 1440/1024/390 review. This brief does not claim Stage 1 acceptance or a passed performance gate.
