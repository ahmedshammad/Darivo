# Stage 4 — Data Research Lead

Discovery brief only. Project Stories and dossiers must make the existing reference evidence usable without upgrading it into current inventory. The full proposed DTO/migration/test boundary is [BACKEND-PROPOSAL.md](BACKEND-PROPOSAL.md).

Existing evidence is 13 real reference projects, three sourced market statistics, nine real organisations plus an aggregate record, and 250 clearly fictional units attached only to fictional projects. Existing facts carry original values, source basis, nullable retrieval date, date precision, confidence and record-level citation scope. These constraints survive every new surface. An export timestamp is not a retrieval date; a hostname is not proof that a publisher is a developer; a project-level listing is not an available residence.

The Story has three explicit subjects: real reference project, authorized demo-project group, and authorized fictional unit. The group exposes only currently visible residences and cannot reveal hidden stock through counts, minima or map summaries. Reference pages lead with availability on request and show no synthetic unit list. Curate editorial claims from documented facts with fact IDs; unknown architecture, permit, imagery rights, completion and amenities stay unknown. Illustrative artwork must be labelled and must not impersonate actual project photography.

Numeric evidence must retain its subject and denominator. Do not compute price per sqm from a headline “up to” area and a separately qualified “from” price. Static display conversion retains native amount, rate date and original qualification; payment currency is a separate preference. Community yields/averages are Demo assumptions and cannot become observed market comparisons. A real reference payment schedule is shown only when its source supports the complete terms; the exact fictional unit schedule remains Demo. Unknown schedules use the requested entity's name without substituting a previous entity.

Dossiers need bilingual subject labels and source-rich appendices that retain URL, basis, fact date/precision, unknown retrieval date and citation scope. Deduplicate repeated source display without discarding different bases or dates. Curated translations preserve original wording where needed. A PDF is a confidential generated snapshot; source freshness and authorization are checked on generation, while already downloaded bytes cannot be revoked remotely.

Named advisors must be sourced from actual profiles. The demo may use a clearly fictional named advisor; it must not fabricate a real employee, portrait attribution, live presence, reply or response-time promise. Availability is an explicitly authored state with a server timestamp, never a simulated heartbeat. Secure messages and copied Brief context remain private to authorized participants. Reassignment and grant revocation require fresh resolution of attached entities, not stale embedded cards.

Research acceptance: original dataset values unchanged; no new real-project facts without source/as-of; reference and Demo labels survive Story, mixed portfolio, comparison, PDF and viewing/enquiry; dates preserve unknown/year/month/day precision; bilingual money and uncertainty remain semantically equivalent. Sentinel leak tests inspect document text and links as well as API/HTML. Rendered bilingual PDF pages must be inspected for clipping, RTL, source legibility and pagination before a dossier is accepted. No external research, data ingestion, schema edit or DB run was performed during this discovery task.
