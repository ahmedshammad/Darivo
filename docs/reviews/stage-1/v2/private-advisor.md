## Three remaining problems / carry-forward work

1. This guide retains edits only in its current page. Stage3 must implement persistent Brief state and reranking without discarding qualifiers; the complete transcript, not a guessed summary, must survive an advisor handoff.
2. Expanded sheets have substantial quiet space for short content. That is acceptable for a predictable spatial component, but the real mobile conversation must balance map visibility with variable-length replies and keyboard height.
3. The comparison hint improves discovery; dense cross-market comparisons and assistive-technology reading order still need testing with real product content. Automated axe results cannot establish a comfortable daily screen-reader workflow.
