# Signature review frames

These PNGs are decoded from the adjacent production signature WebM files with Playwright's bundled ffmpeg. The filename suffix is the requested video timestamp in seconds; the nearest decoded frame represents that moment. No browser or application state was changed for extraction. Times beyond a recording's duration produce no file.
